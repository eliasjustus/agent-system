# User preferences

Only preferences the user stated across projects belong here. Store each new preference at the narrowest scope the user stated: task, project or user layer. Each entry: the preference, its context, source (the user's words and date, or "inferred" with evidence), and decisions it should influence. Inferences stay tentative and never authorise anything. An explicit correction in the same context revises or narrows an entry; old repetitions cannot outvote it.
